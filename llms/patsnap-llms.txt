# Patsnap

> Patsnap is an AI-native innovation intelligence platform for patent, R&D and life-sciences data, serving 18,000+ innovators worldwide. Its Eureka Open Platform exposes 300+ REST API endpoints (356 OpenAPI operations across 47 domains) over 210M+ patents and 2B+ structured data points, plus hosted MCP servers, 140+ Agent Skills and embeddable UI widgets. Authentication is API-key bearer (`Authorization: Bearer sk-...`). API gateway base URL: https://connect.patsnap.com. Backed by SoftBank Vision Fund and Hongshan.

## APIs

- [Patsnap Open Platform API](https://open.patsnap.com/devportal/api-reference): 356 operations - patent data search, patent basic/mining/legal data, valuation, monitoring, enterprise and drug intelligence, chemical/bio data, and Eureka AI/LLM capabilities. Base: https://connect.patsnap.com

## Specs

- [OpenAPI 3.1.0](https://open.patsnap.com/openapi.json): full machine-readable specification (bearer auth, 1829 schemas)

## Integration surfaces

- REST APIs - JSON endpoints over https://connect.patsnap.com
- MCP Servers - 26 hosted servers at https://connect.patsnap.com/{server_id}/mcp (streamable HTTP + SSE, JSON-RPC 2.0)
- Agent Skills - 140+ tools for LangChain, AutoGen and function-calling frameworks
- UI Widgets - embeddable iframe / React / JS components
