Patsnap is an AI-native innovation intelligence platform for patent, R&D and life-sciences data, serving more than 18,000 innovators worldwide. Its Eureka Open Platform exposes 300+ REST API endpoints (patent search, patent legal and mining data, enterprise and drug intelligence, and Eureka AI/LLM capabilities) across 210M+ patents and 2B+ structured data points, plus hosted MCP servers, 140+ Agent Skills and embeddable UI widgets. Backed by SoftBank Vision Fund and Hongshan (Sequoia China), Patsnap is headquartered in Singapore with offices in London, Tokyo, Shanghai and Toronto.

**Areas:** Company · Technology · Patents · Intellectual Property · Innovation Intelligence · Patent Search · Life Sciences · R&D · Analytics · Artificial Intelligence

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Patsnap: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
